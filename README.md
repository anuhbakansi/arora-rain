# arora-rain
# 🌧️ Arora Rain - AI Learning Companion

Arora Rain is a Streamlit app that helps you understand topics, summarise lectures, build notes, practise exams and follow a personalised learning roadmap.

## Features

| Feature | What it does |
|---|---|
| AI Learning Assistant | Explains any topic with key concepts and examples |
| Lecture Summarizer | Short summary, detailed summary and key points (paste text or upload .txt/.md/.pdf/.docx) |
| Smart Notes | Headings, definitions, examples and key points; download as PDF or Word |
| Exam Generator | 10-100 MCQs, Easy/Medium/Hard/Mixed, marks, explanations for wrong answers |
| Learning Roadmap | Field + level + weekly hours -> phases, topics, milestones, resource links |
| Progress Dashboard | Completed topics, exam history, streak, Plotly / Matplotlib / Seaborn charts |
| Celebration Screen | Fireworks animation and an encouraging message after every exam |

## Two engines - everything works either way

1. **AI mode** - paste a Claude API key in the sidebar (or set `ANTHROPIC_API_KEY`). Content is generated by the Claude API through `requests`.
2. **Offline mode** (no key needed) - fetches Wikipedia articles (Requests + BeautifulSoup4), then uses TF-IDF (Scikit-learn) to summarise, build notes and create fill-in-the-blank MCQs. It is simpler than AI mode: examples are limited, and exam size depends on how much source text the topic has.

If an AI request fails, the app automatically falls back to offline mode.

## How each library is used

| Library | Role in Arora Rain |
|---|---|
| **Streamlit** | The whole UI: sidebar navigation, forms, tabs, metrics, file upload, downloads, custom CSS gradients/animations |
| **Pandas** | Stores exams as DataFrames, groups scores by topic/difficulty, builds the activity pivot table |
| **NumPy** | Sentence score normalisation, ranking (`argsort`), roadmap week calculation (`ceil`, `clip`) |
| **Matplotlib** | Average score by difficulty bar chart |
| **Seaborn** | Activity heatmap and score distribution histogram |
| **Requests** | Calls the Claude API and the Wikipedia API |
| **BeautifulSoup4** | Parses Wikipedia HTML into headings and paragraphs (offline engine) |
| **Scikit-learn** | TF-IDF summarisation and keywords; cosine-similarity topic recommendations |
| **Plotly** | Interactive score-trend line chart and roadmap progress gauge |
| **python-docx** | Word downloads for notes, summaries, roadmaps and exam reports |
| **FPDF2** | PDF downloads of the same documents |
| **pypdf** | Reads text from uploaded PDF lectures |

## Installation

Requires Python 3.9+.

```bash
# 1. (optional but recommended) create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. install dependencies
pip install -r requirements.txt

# 3. run the app
streamlit run app.py
```

The app opens at http://localhost:8501.

### Enabling AI mode

- Paste your key in the sidebar **Claude API key** box, or
- set an environment variable before launching:
  - macOS/Linux: `export ANTHROPIC_API_KEY="your-key"`
  - Windows (PowerShell): `$env:ANTHROPIC_API_KEY="your-key"`
- or add `ANTHROPIC_API_KEY = "your-key"` to `.streamlit/secrets.toml`.

The model name can be changed in the sidebar. The offline mode and Wikipedia lookups need an internet connection.

## Project structure

`app.py` is organised into clear sections (modules): Config & Styling, Storage, AI Engine, Offline Engine, Document Export, Charts, Pages. Progress is saved to `arora_data.json` in the folder you run the app from; use *Dashboard -> Danger zone* to reset it.

## Using the app

1. **Home** - overview and recommended topics.
2. **AI Assistant** - enter a topic, read the explanation, mark it as studied.
3. **Summarizer / Smart Notes** - paste or upload a lecture, then download the result.
4. **Exam Generator** - choose topic, difficulty and count, answer, submit, enjoy the celebration, review mistakes. Scoring 60%+ marks the topic as completed.
5. **Roadmap** - build a plan and tick topics off as you finish them.
6. **Dashboard** - watch your progress grow.

## Troubleshooting

- **"No offline source found"** - try a more common topic name, or enable AI mode.
- **AI errors (401/429)** - check your API key and usage limits; the app falls back to offline mode.
- **PDF text looks odd** - PDF downloads use a basic font, so unusual characters become `?`. Use the Word download for full Unicode.
- **Scanned PDFs upload as empty** - they contain images, not text; paste the text instead.
